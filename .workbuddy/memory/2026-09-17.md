## CI/CD 配置优化（my-docs / shareQuotes）

- 讲清 CI vs CD 概念：CI=自动验证（npm ci + build），CD=自动发布（deploy-pages）
- 讲清 `uses` vs `run`：uses=调现成 action（owner/repo@版本），run=自己跑 shell；with=传参
- 改 `.github/workflows/deploy.yml`：新增 pull_request 触发（PR 只构建不发布）
  - 关键坑：`if` 必须写在 `uses` 的 step 之前，否则被传成 action 入参而不生效
  - configure-pages / upload-pages-artifact / deploy job 均加 `if: github.event_name == 'push'`
- 清理废弃路径：删除 `deploy.sh`，移除 `package.json` 的 `deploy:gh-pages` script
- 同步更新 `DEPLOY-NOTES.md`（Workflow 行 + PR 校验说明 + 手动部署废弃说明）
- 环境备忘：本机 bash 的 rm 是 safe-bin shim 会失败，删文件改用 node 的 fs.unlinkSync
