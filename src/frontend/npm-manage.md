# 包管理工具————npm

- 注意：npm 2.0 之前是逐一递归依赖，3.0会按照**就近原则**分析所有依赖关系

当遇到版本冲突时：
版本冲突：依赖包出现版本冲突，多个依赖项都依赖同一个包的不同版本
↓
可以都下载，但是多个依赖可能版本号相同，只安装一个
不同都安装的话，不易维护

npm的扁平化的node_modules解决了依赖地狱问题但是带来了新问题：

- 1.幽灵依赖
- 2.磁盘空间的浪费
- 3.安装速度的瓶颈

pnmp是通过*符号链接*解决上面的问题--解决在我电脑可以 的环境问题
最好是能**强制package-lock.json文件** 不会出现不一致的依赖结构
`直接简单粗暴点，在各个项目里scripts加一个"preinstall": "npx only-allow pnpm" 强制约束`
