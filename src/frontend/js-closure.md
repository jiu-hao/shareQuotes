# 闭包和计算属性（Computed）

#### 闭包简单的说就是一个函数里的东西被带到外面去用了

> 通俗易懂的例子：
> 闭包的内存泄漏，就是把东西存进了保险柜【内存】，虽然我也【不再去开门（不调用）】了，但我手里的【钥匙（引用）没扔掉】，导致那个保险柜一直没法被搬走。
> 全局变量，谁都可以用可以更改 但是闭包不是 有点像私有函数、私有变量

### 闭包有几个特性：

1. 数据私有化
2. 保持状态
3. 占据内存；有内存泄漏的风险；需要手动清理

- 原则： 当您发现有好几个功能长得很像，只有一点点参数不一样（比如称呼不一样），可以用闭包把那个“不一样的部分”先存起来，造出一个专门的小工具。这就叫 **函数柯里化** (名字很洋气，其实就是造模具）。

听起来和vue中的计算属性（Computed）有点像 没错

> Vue 的计算属性（Computed），本质上就是在闭包的基础上封装了一层更高级的“自动化”逻辑
